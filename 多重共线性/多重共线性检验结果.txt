毛利率稳定性 vs 存货周转改善率 多重共线性检验报告
==========================================================================

检验口径：
  因子值版本：毛利率稳定性 = MAD(5x)截尾 + Z-score（不做市值中性化）
              存货周转改善率 = MAD(5x)截尾 + 对数流通市值中性化 + Z-score
  截面时间点：每月末，asof 取「可用日期 <= 月末」最新因子值
  样本范围：当月两因子都非空的全部股票（缺失剔除、不填充）
  检验区间：2022-05 ~ 2024-12（有效截面 32 期）
  相关系数：Pearson（线性）+ Spearman（秩相关，看单调性稳定性）
  计算频率：每月末截面计算一次，得到相关系数时间序列
  判断阈值：|r| < 0.3 无共线性；0.3 ≤ |r| ≤ 0.7 弱到中等；|r| > 0.7 强共线性

数据概况：
  毛利率稳定性因子：1,717 条，可用日期 2022-05-19 ~ 2025-05-06
  存货周转改善率因子：2,579 条，可用日期 2021-03-15 ~ 2025-05-06
  有效截面：32 期（2022-05 ~ 2024-12）
  平均有效股票数：171.2，范围 149 ~ 200

三、共线性判断（按 |r| 均值）：
  Pearson 均值 |r| = 0.0642 → 无共线性（|r| < 0.3）
  Spearman 均值 |ρ| = 0.0526 → 无共线性（|r| < 0.3）
  逐月 |r| 分布（Pearson）：<0.3 共 32 期；0.3~0.7 共 0 期；>0.7 共 0 期
  逐月 |ρ| 分布（Spearman）：<0.3 共 32 期；0.3~0.7 共 0 期；>0.7 共 0 期

四、VIF 换算（两因子，VIF = 1/(1-r²)，用 Pearson 均值）：
  VIF = 1.0041 → 无共线性（VIF < 5）

五、结论：
  两因子间不存在明显共线性（|r| 均值 < 0.3），可同时纳入多因子模型。
